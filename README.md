# ReadyShield

ReadyShield is a mobile disaster-preparedness education application developed for the CM3070 Computer Science Final Project.

The application is designed to support preparedness learning through interactive quizzes, progress tracking, gamified preparedness activities, daily preparedness information, and personalised practice recommendations.

## Main Features

- 120 disaster-preparedness questions across six categories
- General and category-specific quizzes
- Randomised question and answer ordering
- Immediate answer feedback, explanations, and source information
- Persistent quiz-performance history
- Preparedness Profile with category performance statistics
- Rule-based personalised practice recommendations
- Preparedness Missions with persistent completion progress
- Hack of the Day
- About & Sources section
- Progress reset functionality

## Technologies

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage

## Project Structure

- `App.js` - Main application interface and navigation
- `data/questions.js` - Disaster-preparedness question bank
- `data/tips.js` - Preparedness tips
- `utils/performanceAnalysis.js` - Performance analysis and personalised practice recommendation logic
- `assets/` - Application images and icons

## Running the Application

1. Clone or download this repository.
2. Install the required dependencies using `npm install`.
3. Start the Expo development environment using `npx expo start`.
4. Run the application using a compatible mobile device or simulator.

## Project Scope

ReadyShield is an educational disaster-preparedness application. It does not provide live emergency alerts and is not intended to replace official emergency guidance, emergency services, or practical emergency-response training.

## Academic Project

This repository contains the final source code for the ReadyShield application developed as part of the CM3070 Computer Science Final Project.
